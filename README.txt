THE HAVEN — ONE-PAGE STAYCATION WEBSITE
Built as a customizable demo for MarkupHive.

OPEN: Double-click index.html or use VS Code Live Server.
PUBLISH: Upload index.html, style.css, and script.js to a GitHub repository and enable GitHub Pages.

IMPORTANT BEFORE USING FOR A REAL CLIENT:
1. Change THE HAVEN branding, title and property description in index.html.
2. Replace every example Unsplash image URL with real, authorized property photos.
3. Replace the illustrative ₱1,499 price and confirm actual guest capacity, amenities, and policies.
4. In script.js, set MESSENGER_URL to the owner's real Facebook Page link (https://m.me/PAGE_USERNAME).
5. In index.html, replace the generic Google Maps link and location placeholder with the actual property location.
6. Replace MarkupHive's generic footer Facebook link with your actual business URL.
7. Add genuine reviews only if the owner has verified reviews and permission to display them.
8. The booking form PREPARES an inquiry; it does NOT check availability or process payments.
9. Remote images and Google Fonts require an internet connection.
